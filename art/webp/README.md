# High Stakes — all art as WebP

44 unique images converted without resizing using lossless WebP.

- game-assets: 29 selected files from batches 01–05, with readable names.
- references-and-earlier-versions: 15 mockups, original references and superseded generation variants; not additional approved game assets.
- manifest.json: source mapping, dimensions, file sizes and alpha flags.

Every output was decoded and checked against the source for dimensions, alpha and visible pixel equality. Original PNGs remain unchanged. Conversion preserves existing halos, framing and perspective issues; it does not fix them or make candidates production-approved. Source notes included per batch. No missing failed image-edit upload has been reconstructed.
