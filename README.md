# High Stakes

A playable 2.5D garage business game prototype and its long-term production art/design archive.

## Run locally

Serve this folder with `python3 -m http.server 8000`, then open http://localhost:8000. No build or dependency installation required.

## Included

- `index.html`, `style.css`, `game.js`, `assets/`: current playable browser-local prototype.
- `art/webp/`: 44 lossless WebP images; 29 selected batch assets and 15 references/earlier versions, plus conversion manifest.
- `art/png-masters/`: original PNGs, prompts, batch manifests and review notes.
- `docs/`: master game plan and complete production-art checklist.

## Current scope

Plant, harvest, fulfill NPC orders, buy upgrades, save locally. Real token balances, deposits, accounts, multiplayer and competitive prizes are not connected. The project direction is a free-to-play game with Solana/Pump.fun token purchases for cosmetics and bounded convenience. Later conversation decisions supersede broader monetization proposals in the original master plan. Token name and mint are still unconfirmed.

Art is generated candidate work, not approved production output: several assets need halo removal, perspective/anchor fixes, and in-game review. WebP conversion preserves these existing issues. Check batch source notes before integration.

Large ZIP downloads are omitted because their contents are committed individually. No credentials, private hosting identity, or temporary upload helpers are included.
