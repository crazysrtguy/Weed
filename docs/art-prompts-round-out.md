# High Stakes: art prompts to round out the game

Everything below reuses the style wording of your earlier batches (batch-03 props, batch-04 characters, batch-05 decor) so new art matches. Paste a **style block** first, then the **item line**.

## How to use this

1. Generate on a **transparent background** unless it says opaque. If your tool cannot, use a flat light-gray background and tell me; I can cut it out.
2. **Attach reference images** where a prompt says "reference". Consistency matters more than variety.
3. Generate 2–4 options, keep the best, and name the file exactly as shown in **Name** so I can wire it in without guessing. Drop files in `assets/` like last time.
4. Never put text, numbers, prices, names or brand logos in the art. Text is added in code. Do **not** generate the Solana logo or any real brand mark; I add real logos as vectors.
5. Do things in the priority order at the bottom.
