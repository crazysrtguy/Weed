Cloud saves and the weekly league run on a Supabase project. The game works fully offline without it; cloud save is opt-in.

The database password was generated by the dashboard and never recorded; reset it in Project Settings if ever needed. The `service_role`/secret key is never in the repo; the function reads it from its own environment.

## Why the function is deployed as one file

The dashboard's editor cannot resolve `../_shared/*` imports. `node scripts/bundle-function.mjs <out.ts>` builds one self-contained file from the real modules (export lists come from importing them, and the script refuses to build if a needed name is missing). To redeploy: build it, paste it into Edge Functions > hs-api > Code, and deploy. Keep **Verify JWT with legacy secret** OFF (this project signs tokens with newer keys; the function verifies users itself with `auth.getUser`).

After changing `engine.mjs`, `league.mjs` or `server-core.mjs`: `node scripts/sync-server.mjs`, run the tests, rebuild the bundle, redeploy.

## Tests

- `node --test tests/*.test.mjs`: engine, league scoring and server rules, profile cosmetics.
- `node scripts/live-test.mjs`: 20 checks against the REAL project (two anonymous players: import, scored orders, names, leaderboard, visiting rooms, and attacks: forged token, billion-cash import, impossible stock, too many actions, made-up actions, server-clock harvest, locked strain). It leaves throwaway anonymous users; delete with `delete from auth.users where is_anonymous;` in the SQL editor (only while no real players are anonymous).

## Open items and risks

- **Enable CAPTCHA for anonymous sign-ins** (Auth > Attack Protection) before a public launch; otherwise bots can create unlimited anonymous accounts.
- **Email** uses Supabase's built-in sender (heavily rate-limited). Set up custom SMTP before relying on magic links.
- The game loads `@supabase/supabase-js@2.45.4` from esm.sh only when a player opts into cloud save. A CDN script cannot carry an integrity hash; vendor it into the repo before launch.
- Free projects pause after a week of inactivity.
- The other Supabase account (connected to Claude's tools) is at its free-project limit and was not touched.
